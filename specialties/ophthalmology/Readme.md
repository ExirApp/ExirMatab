# تخصص چشم‌پزشکی

![چشم‌پزشکی](https://exirmatab.com/wp-content/uploads/2024/06/Ophtalmologist2.png)

## معرفی

نرم‌افزار مدیریت مطب چشم‌پزشکی اکسیر با بهره‌گیری از ماژول‌های اختصاصی، نیازهای ویژه چشم‌پزشکان را پوشش می‌دهد. پزشکان این حوزه می‌توانند از قلم نوری جهت ثبت شرح حال و معاینات بیمار استفاده کرده و مدارک و تصاویر بیمار (از جمله تصاویر افتالموسکوپی و رتینوگرافی) را در ماژول مدارک نگهداری کنند.
