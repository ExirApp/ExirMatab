# تخصص طب سنتی

![طب سنتی](https://exirmatab.com/wp-content/uploads/2024/06/Teb2.png)

## معرفی

پزشکان این حوزه می‌توانند از قابلیت‌های این نرم‌افزار که به طور ویژه طراحی گردیده است، استفاده کنند. تشکیل پرونده الکترونیک سلامت طب سنتی همراه با ذخیره اطلاعات پیشین بیمار مانند سوابق درمانی و داروهای تجویزی پیشین و همچنین امکان تعریف نسخه درمانی از پیش تعریف‌شده در این نرم‌افزار وجود دارد.
