# معرفی ماژول‌های اولیه

نرم‌افزار مدیریت مطب اکسیر در نسخه پایه شامل مجموعه‌ای از ماژول‌های پرکاربرد است که در جدول زیر معرفی شده‌اند. برای مطالعه جزئیات هر ماژول، روی نام آن کلیک کنید:

| ماژول | توضیح | مستندات |
|-------|-------|---------|
| بخش ویزیت | ثبت شرح حال، تشخیص، دارو و Plan در ویزیت‌های بیمار | [بخش ویزیت](./modules/visit-section/Readme.md) |
| قلم نوری | نگارش نسخه و شرح حال با دستگاه قلم نوری | [قلم نوری](./modules/light-pen/Readme.md) |
| نوبت‌دهی آنلاین | دریافت نوبت اینترنتی مراجعین | [نوبت‌دهی آنلاین](./modules/online-appointment/Readme.md) |
| مدارک | ذخیره و دسته‌بندی مدارک و تصاویر بیمار | [مدارک](./modules/documents/Readme.md) |
| فرم‌ساز | بارگذاری فایل‌های Word و PDF در پرونده بیمار | [فرم‌ساز](./modules/form-builder/Readme.md) |
| اکوکاردیوگرافی | ثبت و گزارش‌گیری اطلاعات اکو بیمار | [اکوکاردیوگرافی](./modules/echocardiography/Readme.md) |
| چک‌لیست | ثبت نتایج آزمایشات بیمار | [چک‌لیست](./modules/checklist/Readme.md) |
| منحنی دور سر | ترسیم منحنی دور سر کودکان | [منحنی دور سر](./modules/head-circumference-curve/Readme.md) |

> 💡 محتوای این بخش خلاصه‌ای از ماژول‌های موجود است؛ جزئیات کامل در صفحات اختصاصی هر ماژول ارائه شده است.
