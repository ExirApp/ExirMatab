# فعال‌سازی و ثبت‌نام

## نسخه‌های نرم‌افزار

نرم‌افزار اکسیر در دو نسخه **پزشک (بخش ویزیت)** و **منشی (بخش پذیرش)** قابل استفاده است. با استفاده از نسخه دمو می‌توانید تا سقف ایجاد **۱۰۰ پرونده** و بدون محدودیت زمانی از آن استفاده کنید.

## فرآیند فعال‌سازی

در صورت خرید نسخه **مطب پایه / مطب شبکه / کلینیک** اکسیر، فرآیندی ساده و امن برای شروع استفاده از امکانات نرم‌افزار وجود دارد:

1. **نصب نرم‌افزار:** پس از نصب نرم‌افزار، کاربران می‌توانند با وارد کردن اطلاعات اولیه مطب یا کاربر (مانند نام، آدرس، تخصص پزشکی و اطلاعات تماس) در تنظیمات نرم‌افزار، پروفایل کاربری خود را ایجاد کنند.

2. **تماس با کارشناسان:** سپس با تماس و هماهنگی با کارشناسان اکسیر، لایسنس منحصر به فرد شما با توجه به ماژول‌های موردنیاز فعال‌سازی خواهد شد.

> 📞 برای دریافت دمو و فعال‌سازی لایسنس با شماره `۰۲۱-۵۴۱۰۹۰۰۰` در تماس باشید.
