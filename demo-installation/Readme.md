# نصب نسخه دمو

## دانلود برنامه

برنامه را از لینک زیر دانلود کنید:

```
https://exirmatab.com/uploads/Exir-latest.zip
```

## مراحل نصب

1. فایل دانلود شده را در همان پوشه Extract کرده و فایل `ExirSetup.exe` را اجرا کنید.
2. بر روی **شروع نصب** کلیک کرده و گزینه **(نسخه دمو)** را انتخاب کنید.
3. محل ذخیره‌سازی پوشه را بر روی درایوی دیگر جز درایو `C` قرار دهید.
4. تیک گزینه **نصب پایگاه داده بر روی این سیستم** را نیز فعال کنید.
5. بر روی مرحله بعد کلیک کنید و منتظر بمانید فرآیند نصب برنامه کامل شود.

> ⚠️ **نکته:** نصب پایگاه داده فقط بر روی سیستم سرور (اصلی) انجام شود.

> ⚠️ **نکته:** در صورت استفاده از نسخه دمو و ایجاد پرونده، بهتر است اطلاعات روی درایو C نباشد تا ریسک پاک شدن اطلاعات نداشته باشید.

## ورود به برنامه

1. پس از تکمیل شدن فرآیند نصب، بر روی ضربدر کلیک کرده و پنجره را ببندید.
2. پس از نصب، آیکون برنامه اکسیر بر روی Desktop قابل مشاهده است؛ بر روی آن کلیک کرده و وارد برنامه شوید.
3. برای ورود اولیه به برنامه، نیاز به نام کاربری و رمز عبور نیست؛ فقط بر روی **وارد شوید** کلیک کنید.

> 💡 **نکته:** تا زمانی که در تنظیمات برنامه بخش کاربران، نام کاربری و رمز عبور تعیین نکنید، با کلیک بر روی «وارد شوید» می‌توانید وارد برنامه شوید.

## محدودیت‌های نسخه دمو

نسخه دمو اکسیر کاملاً رایگان بوده و تا **۱۰۰ پرونده** بدون محدودیت زمانی قابل استفاده می‌باشد.
