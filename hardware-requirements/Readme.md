# نیازمندی‌های سخت‌افزاری

چه کانفیگ سخت‌افزاری برای کار کردن و سازگاری با برنامه مدیریت مطب و کلینیک اکسیر مناسب‌تر است؟

## سیستم پیشنهادی (سرور اصلی)

| قطعه | حداقل مورد نیاز |
|------|-----------------|
| رم (RAM) | ۸ گیگابایت |
| پردازنده (CPU) | Core i5 |
| حافظه (SSD) | ۲۵۰ گیگابایت |
| شبکه | شبکه محلی از طریق LAN |
| اینترنت | اتصال اینترنت (برای نصب و پشتیبانی) |
| سیستم‌عامل | ویندوز ۱۰ |
| پیش‌نیاز نرم‌افزاری | NET Framework 4.7.2 |
